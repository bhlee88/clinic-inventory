직원 승인 기능 안내

현재 버전은 오프라인 시험판입니다. 이름+PIN 인증과 관리자 승인/차단은 서버 인증이 필요하므로 아직 활성화하지 않았습니다. 화면에서 관리자로 전환해도 실제 접근 권한은 생기지 않습니다.

운영용 버전에서는 직원 가입 신청 → 관리자 승인 → 승인된 직원만 접근하도록 구현합니다. PIN은 서버에서 검증하고, 관리자 차단 시 데이터 접근도 막도록 설계합니다.

이 시험판의 데이터는 현재 브라우저에만 저장됩니다. 앱 삭제·브라우저 데이터 초기화 시 사라질 수 있습니다. 환자 정보나 민감한 개인정보를 입력하지 마세요.
